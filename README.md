# CampusGrid

A campus utility web app/PWA for Lovely Professional University students, built as an independent student project.

**Live app:** [iamaryaann.github.io/lpu-campusgrid](https://iamaryaann.github.io/lpu-campusgrid/)

## What it includes

- Academic helpers such as attendance, timetable, and grade calculations
- Hostel, mess, and day-to-day student utilities
- Community tools for campus listings, lost and found, and finding project teammates
- A responsive interface designed for use on phones and desktops

## Technology

The repository includes a JavaScript web app, a Python REST API, and an SQLite data layer. Some features depend on the separately hosted API and its configuration; a static GitHub Pages deployment cannot run the API itself.

## Project status

CampusGrid is an independent student project and is not an official LPU app. University information and services can change; confirm important details with LPU before relying on them.
