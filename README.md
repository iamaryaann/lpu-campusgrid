## Full-Stack Backend Architecture (v8.0)
- **Python REST API + SQLite3 Relational Database (`server.py` + `campusgrid.db`):**
  - 5 Relational Tables: `students`, `bazaar_items`, `lost_found`, `teamup_posts`, `mess_poll`
  - REST Endpoints: `GET /api/health`, `GET /api/community`, `POST /api/bazaar`, `POST /api/lostfound`, `POST /api/teamup`, `POST /api/poll`, `POST /api/cloud-save`, `POST /api/cloud-load`
- **24×7 Cloud REST Database Sync:** Real-time cross-device cloud sync for GitHub Pages and LPU Sophos Wi-Fi (`Save to DB` / `Load from DB` using LPU Registration Number + 4-digit PIN).
